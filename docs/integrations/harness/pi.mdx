Use the NVIDIA NeMo Fabric `nvidia.fabric.pi` adapter to run Pi 0.84.2 through
its persistent JSONL RPC mode.

## Install the Adapter

To install the NeMo Fabric runtime, adapter, pinned Pi npm distribution, and
packaged Node.js runtime in one environment, run:

```bash
pip install "nemo-fabric[pi]"
```

To install the adapter, Pi, and Node.js without the NeMo Fabric runtime, run:

```bash
pip install "nemo-fabric-adapters-pi[harness]"
```

The `harness` and `full` extras install the first-party
`nemo-fabric-pi-cli-bin` distribution. That package contains Node.js 22.19.0
and the shrinkwrap-locked official `@earendil-works/pi-coding-agent` 0.84.2 npm
distribution. Runtime startup does not invoke `npx`, search `PATH` for Pi, or
install packages over the network.

Use the bare adapter only when the execution environment already provides a
reviewed Pi 0.84.2 executable:

```bash
pip install nemo-fabric-adapters-pi
```

For the complete platform list and split-environment guidance, refer to the
[Pi adapter package guide](https://github.com/NVIDIA/NeMo-Fabric/tree/main/adapters/pi).

## Resolve Explicit Paths

Resolve the installed Pi wrapper and descriptor from their installation
locations:

```python
import os
import sysconfig
from pathlib import Path

scripts = Path(sysconfig.get_path("scripts")).resolve()
pi_executable = scripts / ("nemo-fabric-pi.exe" if os.name == "nt" else "nemo-fabric-pi")
descriptor = (
    Path(sysconfig.get_path("data")).resolve()
    / "share/nemo-fabric/adapters/pi/pi.fabric-adapter.json"
)
```

Pass absolute local paths for the Pi executable, descriptor, workspace,
artifact root, and every skill directory. Each skill directory must contain a
`SKILL.md` file.

## Configure the Adapter

The adapter accepts exactly one model role named `default`. It maps
`provider`, `model`, and `api_key_env` to Pi. The closed model schema rejects
base URLs, temperature, model settings, and extensions.

The adapter maps `skills.paths` by disabling ambient skill loading and passing
each explicit directory to Pi. It does not map instructions, tools, MCP,
telemetry, streaming, updates, cancellation, or service behavior. Pi's ambient
extension discovery remains Pi-native and is outside the normalized adapter
surface.

The following configuration uses only explicit absolute paths:

```python
from nemo_fabric import DiscoveryConfig, EnvironmentConfig, FabricConfig
from nemo_fabric import HarnessConfig, MetadataConfig, ModelConfig, RuntimeConfig
from nemo_fabric import SkillConfig

config = FabricConfig(
    metadata=MetadataConfig(name="pi-agent"),
    discovery=DiscoveryConfig(local_paths=[descriptor]),
    harness=HarnessConfig(
        adapter_id="nvidia.fabric.pi",
        resolution="preinstalled",
        settings={"pi_executable": str(pi_executable)},
    ),
    models={
        "default": ModelConfig(
            provider="nvidia",
            model="nvidia/nemotron-3-super-120b-a12b",
            api_key_env="NVIDIA_API_KEY",
        )
    },
    skills=SkillConfig(paths=[Path("/absolute/path/to/skill")]),
    runtime=RuntimeConfig(
        artifacts=Path("/absolute/path/to/artifacts"),
        timeout_seconds=900,
    ),
    environment=EnvironmentConfig(
        provider="local",
        workspace=Path("/absolute/path/to/workspace"),
        artifacts=Path("/absolute/path/to/artifacts"),
    ),
)
```

Set the environment variable named by `api_key_env` before starting the
runtime. The adapter first checks the explicit Fabric environment, then the
host environment. It writes only an environment-variable reference to Pi's
private runtime-local `auth.json`; it never persists the API key.

## Run Multiple Turns

One NeMo Fabric runtime owns one persistent Pi process. The following code
reuses it for two ordered invocations and stops it through the context manager:

```python
from nemo_fabric import Fabric

fabric = Fabric()
plan = fabric.plan(config, base_dir=Path("/absolute/path/to/workspace"))
report = await fabric.doctor(config, base_dir=Path("/absolute/path/to/workspace"))

async with await fabric.start_runtime(
    config,
    base_dir=Path("/absolute/path/to/workspace"),
) as runtime:
    first = await runtime.invoke(input="Review the workspace.")
    second = await runtime.invoke(input="Summarize the earlier finding.")
```

Pi reports completion at `agent_settled`. Failed or aborted Pi turns return a
failed normalized result. Malformed or oversized JSONL, correlation failures,
EOF, and deadlines fail the runtime and close the process.

The adapter does not claim automated conformance because the public
conformance suite is not yet available.
